## Description
This repository contains a completed web development assignment focused on creating and styling HTML forms using Bootstrap 5 and managing input validation. The main objective was to practice responsive layouts, form control styling, layout grid usage, and JavaScript validation feedback.



### Task 1: Basic HTML Form Refactoring
In this task, an existing standard HTML form was reviewed and prepared for modernization. The overall layout was structure-checked to make sure all basic form inputs, labels, and form groups followed accessible semantic HTML practices before Bootstrap integration.

### Task 2: Bootstrap Form Styling
Bootstrap form classes were applied across all form controls. Fields were visually aligned and styled with form-control, form-label, and form-text classes. Page responsiveness and structural alignment were achieved using the Bootstrap grid system with row and column containers. Appropriate placeholders and helper messages were added to guide user input.

### Task 3: Bootstrap Validation Styles
Custom client-side form validation was configured using the novalidate attribute on the form element and the needs-validation class. Dynamic error and success styling were integrated alongside invalid-feedback and valid-feedback components, providing visual feedback to users upon submitting incomplete or incorrect data.
<img width="1898" height="267" alt="image" src="https://github.com/user-attachments/assets/c7b2add0-39fc-4260-8a67-300503676912" />

### Task 4: Advanced Form Project
A comprehensive registration form was implemented. It incorporates a range of input controls including first name, last name, email, password, gender selection via radio buttons, hobbies selection via checkboxes, and country selection via a dropdown menu. Standard action buttons for form submission and form resetting were added. Form controls use HTML5 validation parameters such as required and minlength to enforce input requirements before submission.
